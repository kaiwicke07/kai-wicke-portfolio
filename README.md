# Kai Wicke, engineering portfolio

A static one-page portfolio: plain HTML, CSS and JavaScript, no build step.

- `index.html` – the page
- `styles.css` – all styles
- `main.js` – plays project videos while they are on screen
- `assets/` – project photos, screenshots and videos
- `Kai_Wicke_CV.pdf` – the CV

Deployed on Vercel: every push to `main` goes live.

To preview locally, serve the folder, for example `npx serve .`
